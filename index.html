NORMI DIAN

A tongue built on Old English. A translator that turns any language into it.

Normidian is a constructed language — grammar rules and all. The words lean Old English: þ for th, ð for the soft th, ƿ for w, æ and œ hiding in the vowels.

The dictionary is alive — 761 words and growing, kept on GitHub so every copy of the translator can pull the latest.

þ THE GRAMMAR

Normidian does not borrow grammar from English. It has its own.

ARTICLES SHIFT WITH CASE

A noun's article changes depending on whether it is the doer, the done-to, or the owner.

living subject   → ðse
living object    → ðnes
dead subject     → ðsaþ
recipient        → þœn

NOUNS TAKE SUFFIXES

Nouns carry their own case endings on top of the article.

root             → swiarƿ   (sword)
suffixes         → þnes þes þas þe

VERBS AGREE WITH YOU

Conjugation is by who is doing it — not a generic -s.

I ...            → root + ies
you ...          → root + ðus
he/she/it ...    → root + ƿues

NEGATION IS A PREFIX

To make something false, bind it with ne-.

see    → ġeseoh
not see → ne-ġeseoh

þ THE TRANSLATOR

A desktop app built on CustomTkinter. It translates to and from Normidian.

ANY LANGUAGE → NORMI DIAN

Type in English — or, over the network, in almost any language — and the engine bridges it through to the tongue.

NORMI DIAN → ANY LANGUAGE

The reverse path too: Normidian out, plain English (or your language) back.

COLOUR-CODED GRAMMAR

Every word is tagged and coloured by part of speech, with a live legend — nouns, verbs, adjectives and the rest, at a glance.

WORKS OFFLINE

The dictionary caches locally. No connection, no problem — it falls back to the last synced word list.

COPY & READ ALOUD

Grab the translation in one click, or have the machine speak it (when pyttsx3 is present).

DICTIONARY MANAGER

A second app for growing the tongue — browse, edit, and save words back to the GitHub word list.
